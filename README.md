# Smart Wardrobe v0.2.2 — 示意圖及純色背景去背

## 主要更新
- 沒有照片的 13 件初始衣物，會依分類及顏色顯示**示意圖**（非實物照片），可直接加入穿搭工作室，測試拖曳、縮放、儲存。
- 已有照片的單品卡片增加「去背（純色）」及「還原原圖」。純色去背是本機 Canvas 的連通區域演算法，**不是 AI 去背**，對複雜背景可能失敗。
- 去背後儲存透明 PNG data URL，保留原圖於同一衣物紀錄；JSON 匯出包含照片與原圖，備份檔可能變大。
- 原本 IndexedDB 名稱與 schema 保持不變，舊資料可沿用。

## 更新方式
1. 在舊版設定頁先匯出 JSON 備份。
2. 將解壓縮後所有檔案上傳至 GitHub Pages Repository 根目錄，取代同名檔案。
3. 等待部署完成，關閉再重開 iPhone PWA。
4. 進入「推薦 → 自由搭配工作室」，選擇無照片的衣物，確認出現「示意圖」圖層。
5. 新增一張純白背景衣物照片，在衣櫃按「去背（純色）」測試。

## 限制
- 示意圖只反映分類及大致顏色，不能推論實際版型。
- 純色去背不適用所有圖片，若顏色與背景相近，可能錯誤移除衣物部分。
- 尚未導入 AI 虛擬試衣、專用去背模型或自動穿搭生成。
- 本機照片與資料不會自動同步至其他裝置。


## v0.2.3 改善
- 「目前搭配」每件衣物旁都有「✕ 移除」，點錯可單件刪除，不需清空。
- 衣物去背新增可調容差（0–100）與邊緣柔化（0–40），可以重新套用原始照片；仍屬本機純色背景去背，非 AI 精細去背。

## v0.2.4（實驗性 AI 去背）
- 衣櫃有照片的單品新增「AI 去背（測試版）」。點擊後下載第三方模型並在瀏覽器內進行分割，預覽前後對比，確認後才會儲存；可還原原圖。
- 使用 `@imgly/background-removal` 的 CDN ESM 版本，**需要網路**。首次下載模型較大，iPhone Safari 可能因記憶體、跨來源模型檔案或 CDN 相容性而失敗。此版本尚未在 iPhone 實機驗證；失敗不會覆蓋原圖。
- 模型來源為第三方；雖然推論設計為本機執行，仍請依需求評估第三方程式與模型下載的隱私風險。
- 這是 AI 語意去背而非「指定哪一件衣物」的互動式分割；同一張照片出現其他外套時可能一起保留。
- 保留 v0.2.3 單件衣物移除功能，資料庫版本維持 2。更新前請匯出 JSON 備份。
